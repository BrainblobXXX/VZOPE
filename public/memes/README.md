# Мемы для stage 1

Сюда можно просто кидать картинки. Приложение само подхватит их при
следующем обновлении страницы — пересобирать ничего не нужно, пока
запущен `npm run dev`.

## Форматы

- `.jpg`
- `.jpeg`
- `.png`
- `.webp`
- `.gif`
- `.avif`

## Имя файла — служебное

Имя файла не показывается на карточке: оно нужно для сортировки и alt-текста.

Например:

```
когда_услышал_что_телевизор_можно_починить.jpg
пельмени_7_минут.png
жаба_смотрит_как_на_предателя.gif
```

Подчёркивания и дефисы заменяются на пробелы, расширение убирается.
Этот текст используется только для доступности, на экране его нет.

## Порядок

Файлы сортируются по имени. Если хочешь задать порядок — начинай имя
с номера:

```
01_когда_нашёл_кассету.jpg
02_жаба_из_8_бит.png
03_пельмени_7_минут.png
```

## Если папка пустая

Приложение покажет встроенные emoji-заглушки. Это нормально: как только
появится хотя бы один файл, лента переключится на картинки.

## Ограничения

- Без политики, религии, 18+ и персональных данных.
- Без чужих водяных знаков.
- GIF — до 10 МБ, без бесконечной яркой вспышки.
- Лучше горизонтальные или квадратные картинки: карточка вписывает мем
  целиком (`contain`), фон остаётся тёмным.

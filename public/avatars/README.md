# Аватары для stage 1

Сюда кладутся фотографии пользователей. Имя файла — это ID пользователя.

## Обязательные имена

| Файл | Кто |
|---|---|
| `me.jpg` | свой профиль |
| `u1.jpg` | КАСС_КРОТ |
| `u2.jpg` | ДЯДЯ_ВОВАН |
| `u3.jpg` | ЛЮБА_90Х |
| `u4.jpg` | ГОСТЬ_С_КУХНИ |
| `u5.jpg` | ПИКСЕЛЬНАЯ_ДАША |
| `u6.jpg` | МАТРИЧНЫЙ_ПРИНТЕР |
| `u7.jpg` | ВАСЯ_С_БАЛКОНА |
| `u8.jpg` | ШУМ_И_ПОМЕХИ |

Расширение может быть `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.avif`.
Если файла нет — показывается старый пиксельный аватар.

## Свой аватар

В профиле можно нажать на аватар и выбрать файл. Он сохранится в
`localStorage` браузера и переживёт перезагрузку. Это только для stage 1:
на этапе 2 загрузка пойдёт на сервер.

## Ограничения

- Квадратные или вертикальные фото.
- Лицо лучше по центру: аватар кадрируется в круг.
- До 5 МБ.
